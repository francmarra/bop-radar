# UX & Accessibility Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the GT7 BoP Radar site BoP-focused and usable by people of all ages (WCAG 2.1 AA).

**Architecture:** Static SPA in `site/`, hash routes, no build step. Split `site/app.js` into native ES modules;
pure logic (formatting, search, "most affected", i18n) lives in DOM-free modules tested with `node --test`;
pages render HTML strings as today. Data JSON and the Python pipeline are untouched.

**Tech Stack:** Vanilla JS (ES modules), CSS custom properties, Node 22 `node:test` for JS unit tests, pytest (existing).

**Spec:** `docs/superpowers/specs/2026-10-16-ux-a11y-design.md`

## Global Constraints
- Only `site/` and `tests/js/` change; `src/`, `data/`, `site/data/` untouched; `pytest -q` stays green.
- No build step, no npm dependencies; modules load via `<script type="module" src="js/main.js">`.
- Base font 18 px (`html { font-size: 112.5% }`, everything else in `rem`); no text below 15 px (0.8333rem).
- Text contrast ≥ 4.5:1 in both themes; interactive targets ≥ 44×44 px; visible `:focus-visible` outline.
- Meaning never by colour alone: verdicts render as "▲ Faster" / "▼ Slower" / "◆ Mixed" (PT: "▲ Mais rápido" / "▼ Mais lento" / "◆ Misto").
- Term changes (EN/PT): Fast/Medium/Slow tracks · Pistas rápidas/médias/lentas; Performance level (PP) · Nível de performance (PP); Level · Nível; Strengths · Pontos fortes.
- Nav: Home · BoP updates · Help. Tracks unlinked; `#/tracks`, `#/track/...` still route (code kept).
- Every `localStorage` access in try/catch; page works when it throws.
- All user/data strings go through `esc()` before entering HTML.
- Commit per task on `feat/ux-a11y`; no merge to `main` without Francisco's OK.

## Review Focus
1. Search with case/accents/partial words ("porsche", "CITRO", "Citroën", "gr3 ferrari") → finds the car; test in Task 6.
2. Class with no changes in the latest update (`counts[g]` missing) → card says "No changes for Gr.X" instead of crashing; test in Task 6.
3. `localStorage` blocked (private mode) → theme/lang toggles still work for the session; test in Task 2.
4. Car whose history has a single entry (never changed) → car page shows "No BoP changes yet" not an empty list; check in Task 7.
5. Old links `#/tracks`, `#/about` → still render (about redirects to Help); check in Task 4.
