# Interface mais simples (mobile-first) — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Navegação a um toque, linhas de carros compactas e páginas com o secundário recolhido, sobretudo no telemóvel.

**Architecture:** Mudança só em `site/` (SPA vanilla JS, sem build). A navegação continua a viver no shell `site/index.html`, que o pré-render (`src/gt7bop/render.py: page_html`) reutiliza. Uma função partilhada `carRow()` em `site/js/row.js` substitui as linhas de carros de ranking, semana, atualizações e pistas. Secções recolhidas com `<details>` nativo; pesquisa global num `<dialog>` nativo; painel ⚙ com o atributo `popover` nativo.

**Tech Stack:** HTML/CSS/JS (ES modules), `node --test`, pytest.

**Spec:** `docs/superpowers/specs/2026-10-26-simple-ui-design.md`

## Global Constraints

- URLs iguais, sem rotas novas; `help/` continua a existir.
- Nenhum dado removido do site: o secundário fica em `<details>` ou na página do carro.
- EN e PT para todo o texto novo (o teste "EN and PT have the same keys" tem de passar).
- Contraste AA e "no font size below 15px / .8333rem" (`tests/js/contrast.test.mjs`); alvos de toque ≥ `var(--tap)`.
- `prefers-reduced-motion` respeitado; nada de animação nova.
- Sem dependências novas; `api/`, `web/`, pipeline Python e `update.yml` não mudam.
- Breakpoint do telemóvel: `max-width: 767px` (spec: "< 768 px").
- Todo o texto vindo de dados passa pelo `html` de `site/js/format.js` (escape por omissão).

## Review Focus

1. **Barra em baixo dentro do `.top`:** o `.top` tem `backdrop-filter`, que torna o `position: fixed` relativo ao cabeçalho. No telemóvel, `backdrop-filter: none` no `.top` — verificar na captura a 390 px que a barra está colada ao fundo do ecrã.
2. **Teclado aberto no telemóvel:** com a pesquisa aberta, a barra não pode ficar por cima da lista de sugestões → o `<dialog>` é modal e cobre o ecrã inteiro (verificado na captura da Tarefa 5).
3. **Gráfico dentro de `<details>`:** desenhado com `box.clientWidth`; dentro de uma secção fechada a largura é 0 → o Histórico fica `open` por omissão (Tarefa 3) e o código mantém o fallback `|| undefined`.
4. **Nome de carro longo** (ex. "Lancer Evolution Final Edition Gr.3") numa linha de 390 px → reticências, sem scroll horizontal (teste de markup na Tarefa 2 + captura).
5. **Página pré-renderizada sem JS:** a navegação do shell tem de ter links reais (`<a href>`) para Semana/Ranking/BoP; só a Pesquisa é botão (teste de shell na Tarefa 1).
