# Pre-render, SEO and share images — design

Date: 2026-10-16 · Branch: `feat/seo-prerender` · Senior-review item 2 · decided autonomously.

## Problem
Routes are `#/car/...`: search engines index one URL (the sitemap lists one), so 123 car pages, 23 update pages and
the weekly guide are invisible. Link previews (Discord, Reddit, X) do not run JS and there is no `og:image`, so
shared links show bare text.

## Decisions
1. **Real URLs** `car/<id>/`, `update/<v>/`, `updates/`, `week/`, `help/` (`track/<id>/<g>/` kept, unlinked).
2. **Build output `dist/`** (gitignored): copy of `site/` plus one `index.html` per URL, generated by
   `gt7bop render [--out dist] [--site-url https://francmarra.github.io/bop-radar/]` from `site/index.html` as the
   shell. `site/` stays the editable source and still works unrendered for quick local dev.
3. **Per page head**: `<title>`, meta description, canonical (absolute), `og:title/description/url/image`,
   `twitter:card=summary_large_image`, JSON-LD (`WebSite` on home, `BreadcrumbList` on car/update pages).
4. **Pre-rendered body** (English, text-first, inside `#app`): enough for crawlers without JS — headings, the
   car's class/level/rank/source and BoP history; update pages' changed cars; week races with top cars; home
   top 10 per class and latest update. The SPA replaces it on boot (user's language).
5. **Asset paths**: rendered pages rewrite `style.css`, `js/main.js`, icons to depth-relative paths. The JS derives
   its base from `import.meta.url` (`new URL("../", import.meta.url).pathname`), so `data/` fetches and links work
   at any depth and on any host (`/bop-radar/` on Pages, `/` locally).
6. **Router**: path-based (`history.pushState`, `popstate`); internal `<a>` clicks are intercepted (no modifier keys,
   same origin, under base). Old `#/…` links are rewritten with `history.replaceState` on boot. `dist/404.html` =
   shell, so unknown paths still boot the SPA (GitHub Pages serves it).
7. **sitemap.xml** in `dist/` with every URL and `lastmod` (car: latest version date; update: its date; others:
   generated date). `robots.txt` points at it.
8. **Share images** `og/<page>.png`, 1200×630, via Pillow (optional dependency group `render`; CI only). Default card,
   one per update ("BoP 1.71 · Gr.3: 13 faster, 8 slower…"), one per car (name, class, level/rank, last change).
   Fonts: DejaVu (Ubuntu runner) or Arial (Windows), else Pillow default. Without Pillow, pages point to `og/default.png`
   if present and skip the rest.
9. **CI**: after data steps, `uv run --extra render gt7bop render --out dist`, upload `dist` instead of `site`.

## Testing
- pytest `tests/test_render.py`: files for every page; head tags present, escaped and absolute; canonical matches
  path; relative asset prefix per depth; sitemap lists all URLs; 404 exists; week/update/car body content.
- pytest OG: 1200×630 PNG produced when Pillow is available (skip otherwise); missing font falls back.
- node: router helpers (`basePath`, `pathOf`, `hashToPath`, `link`), pure.
- Chrome on `dist/` served locally: deep-link reload, in-app navigation + back/forward, old hash link redirect,
  language switch; Lighthouse SEO + a11y 100. After deploy: `curl` a car URL shows its title/og tags.
